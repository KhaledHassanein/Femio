The logo is always English "femio" — never transliterated. In RTL layouts the English lockup is used as-is (the app's UI & content remain fully Arabic/RTL; only the brand mark is fixed).

App icon

Bloom on a warm off-white squircle — legible on any home screen. A deep-violet variant can be produced for dark contexts.

Clearspace & minimum size

Clearspace = the mark's center-dot diameter on all sides (≈¼ mark height).
Minimum sizes. Mark: 20px (digital), 8mm (print). Horizontal lockup: 96px wide. Below that, use the mark alone. Never recolor petals, stretch, add effects, or place the gradient mark on a busy/low-contrast background — use the mono/reversed versions instead.
