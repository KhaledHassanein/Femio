# Flags for the language switcher

`gb.svg`, `sa.svg`, `fr.svg` are from the flag-icons project (https://github.com/lipis/flag-icons,
MIT licence, copyright Panayiotis Lipiridis; licence text in `LICENSE-flag-icons.txt`), 4:3 set,
unchanged. `es.svg` is Spain's civil flag (plain stripes, no coat of arms) drawn by hand, because
the state flag's SVG weighs 80 KB for a 20-pixel icon.

A flag stands for the language's name next to it (owner decision, 2026-10-29: "language names
with flags for each language to be identifiable"), never alone: Arabic, French and Spanish each
belong to many countries. The names are in `apps/web/src/lib/locales.ts`.
