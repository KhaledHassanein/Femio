# femio for Android (Flutter)

The product (D7, D8, ADR-070): a private app. Her records live on the phone, and femio has
no network code of its own (ADR-080). The only traffic is Google's: the Gemini Nano model
download through Android's AICore, and Cloud boost through Firebase AI Logic, which sends
only a question she approved or her four-band profile, and only after she agrees (ADR-079,
ADR-080). Spec: `docs/30_REVAMP/04_ANDROID_APP_SPEC.md`.

- **Application ID `com.femioapp.femio`.** Permanent once on Google Play: changing it
  publishes a different app and strands every install. Do not rename it.
- **Colours** come from the website's tokens: `lib/theme/tokens.g.dart` is generated by
  `node scripts/design/tokens-to-dart.mjs` (the web gate fails if it is stale).
- **Maths** (`lib/domain/`) are twins of `apps/web/src/lib`, held together by the JSON
  in `/fixtures/domain`, which both test suites load.
- **Strings**: `lib/l10n/app_{en,ar,fr,es}.arb`. Arabic is right-to-left and uses
  Western digits (ADR-069).

```sh
flutter pub get
flutter analyze && flutter test                       # what CI runs
flutter test --update-goldens test/screens_test.dart  # screenshots → test/screenshots/
flutter build apk --release --split-per-abi           # installable APKs
```

Toolchain in a cloud session: Flutter (newest stable at least two weeks old) and the
Android SDK command-line tools under `/root/sdk`, see `docs/STATE.md`.
