## 🏢 Account Setup

### Step 1: Create Developer Account
1. Go to [Google Play Console](https://play.google.com/console)
2. Pay one-time $25 registration fee
3. Complete identity verification (2-3 days)
4. Set up organization details or personal developer

### Step 2: Create New App
1. Click **"Create app"**
2. Fill in details:
   - **App name:** Femio
   - **Default language:** English (United States)
   - **App or game:** App
   - **Free or paid:** Free
   - **Declarations:** Privacy Policy Required, User Data Collection

## 🔧 Technical Setup Steps

### 1. Generate Release Keystore
```bash
keytool -genkey -v -keystore femio-release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias femio
```

**CRITICAL:** Backup this keystore securely! Loss = unable to update app.

### 2. Configure build.gradle (app level)
```gradle
android {
    defaultConfig {
        applicationId "com.femio.tracker"
        versionCode 1
        versionName "1.0.0"
    }

    signingConfigs {
        release {
            storeFile file("femio-release-key.jks")
            storePassword System.getenv("KEYSTORE_PASSWORD")
            keyAlias "femio"
            keyPassword System.getenv("KEY_PASSWORD")
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true
            shrinkResources true
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
}
```

### 3. Build App Bundle
```bash
flutter build appbundle --release
```

Output: `build/app/outputs/bundle/release/app-release.aab`

### 4. Test AAB Before Upload
```bash
bundletool build-apks --bundle=app-release.aab --output=app.apks --mode=universal
bundletool install-apks --apks=app.apks
```
