Words you will meet

Package name
The app's permanent ID on Play. Google reads it from the first file you upload. It can never change.
App bundle (.aab)
The file you upload. Claude builds it; Google turns it into the install for each phone.
Upload key
A file on your PC that signs every bundle so Google knows it came from you. Step 1 makes it.
Play App Signing
Google keeps the final signing key. If your upload key is ever lost, you ask Google to reset it (a few days' delay, not a lost app).
Track
Who gets a release: internal (you and up to 100), closed (invited testers), open (anyone who joins), production (everyone).
Opt-in link
The link a tester opens once to join a track, then installs from Play as normal.
Is the release build broken? No. It is ready except for one thing only you can make: the upload key (Step 1). Without it the build signs itself with a test key, and Play refuses that on purpose, so nothing wrong can be uploaded by mistake. Claude built a test release bundle on 25 November (60 MB) and read what is inside: the permissions are internet, network state, notifications, start-after-restart, vibrate, Google Play billing and the on-phone AI service; there is no advertising ID, and Firebase's installation-ID library is not in it.
1

Make your upload key

Once · about 10 minutes · on this PC

  1. Open your password manager and create an entry called femio upload key with a long new password. You will type it twice below.

  2. Press Start, type PowerShell, press Enter. Paste this line and press Enter (it makes a private folder):

    New-Item -ItemType Directory -Force E:\_Private

  3. Paste this line and press Enter. It uses the key tool that came with Android Studio:

    & "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkey -v -keystore E:\_Private\femio-upload-keystore.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias upload

  4. It asks for a keystore password. Paste your new password and press Enter. Nothing appears while you type; that is normal. Paste it again when asked.

  5. Answer the questions, pressing Enter after each:

    QuestionType
    What is your first and last name?Khaled Hassanein
    Organizational unit?(just press Enter)
    Organization?KM Digital Labs
    City or Locality?Cairo
    State or Province?Cairo
    Two-letter country code?EG
    Is CN=... correct?yes
    Key password for <upload>press Enter (same as the keystore password)

    You should see "Storing E:\_Private\femio-upload-keystore.jks". If PowerShell says the file cannot be found, Android Studio is installed somewhere else: tell Claude what the error says.

  6. Paste this line to open a new, empty settings file in Notepad. Click Yes when it asks to create the file:

    notepad E:\Femio\apps\mobile\android\key.properties

    Paste these four lines into Notepad, replace both YOUR_PASSWORD with your password, then File → Save and close Notepad:

    storeFile=E:/_Private/femio-upload-keystore.jks storePassword=YOUR_PASSWORD keyAlias=upload keyPassword=YOUR_PASSWORD

    Git is set to ignore this file, so it never goes into the code history. Claude copies it into the build folder without opening it.

  7. Make two backups of E:\_Private\femio-upload-keystore.jks: attach it to the password-manager entry, and copy it to a USB drive you keep offline.

  8. Type keystore ready in the Claude session. Never paste the password there.

2

Finish "Set up your app" in Play Console

Once · about 45 minutes · play.google.com/console → femio → Dashboard

You already created the app. The Dashboard shows a list called "Set up your app". Open each item, answer, and press Save. Play changes its wording now and then; if a question here does not match the screen, choose the closest and tell Claude.

  1. Privacy policy

    Paste and Save:

    https://femioapp.com/en/privacy

  2. App access

    Choose All functionality in my app is available without any access restrictions. Save.

  3. Ads

    Choose No, my app does not contain ads. Save.

  4. Content rating

    Start questionnaire. Email: info@femioapp.com. Category: All Other App Types (the closest; there is no health category). Then answer each question No: violence, fear, sexuality or nudity, bad language, drugs, alcohol or tobacco, gambling, crude humour.

    For "Does the app allow users to interact or exchange content?": No. "Shares the user's current location?": No. "Allows users to purchase digital goods?": No. "Unrestricted internet access (a browser)?": No.

    Reproductive-health education is not sexual content. Accept the rating it gives; do not try to steer it. Save → Submit.

  5. Target audience and content

    Age groups: tick 18 and over only. "Could your store listing unintentionally appeal to children?": No. Save.

  6. News apps

    No. Save.

  7. Advertising ID

    "Does your app use advertising ID?": No. Save.

  8. Government apps

    No. Save.

  9. Financial features

    Tick My app doesn't provide any financial features. Save.

  10. Health apps

    Tick only what femio really does:

    • Period tracking (under Health and fitness)
    • Reproductive and sexual health (fertile window, contraction timer, baby-movement log)
    • Medical reference and education (the Learn library)

    Do not tick medical device, clinical decision support or disease prevention, and do not choose "My app doesn't provide any health features". Save.
