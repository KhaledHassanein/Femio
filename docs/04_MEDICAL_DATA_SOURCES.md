# Femio V2 — Professional Gynecology Data & Content Sources
Purpose: authoritative references for conditions, patient education, tools, and clinical logic. Every Femio article must cite ≥1 Tier-1/2 source, carry a review date, and a named medical reviewer.

## Tier 1 — Free, reusable / public-domain (build the library on these)
| Source | What it gives us | Access / license |
|---|---|---|
| **MedlinePlus (NLM/NIH)** | Patient education on 1000+ topics incl. full gyn range; **MedlinePlus Connect API**; English + Spanish | Public domain (US Gov). Free API. Best backbone. |
| **NIH institutes: NICHD, ORWH, NIA (menopause), NIMH (PMDD/PPD)** | Condition deep-dives, pregnancy, menopause aging content | Public domain |
| **CDC** | Reproductive health, contraception (US MEC charts), pregnancy, screening schedules | Public domain |
| **Office on Women's Health (womenshealth.gov)** | Consumer-grade A–Z women's health topics, ES included | Public domain |
| **NHS.uk** | High-quality plain-language condition pages | Open Government Licence (attribution; syndication API available) |
| **WHO** | Global guidelines (contraception MEC, maternal health, menopause fact sheets); multilingual incl. Arabic & French | CC BY-NC-SA — usable with attribution |
| **PubMed / PMC APIs (E-utilities)** | Evidence citations for every article | Free API |
| **openFDA / DailyMed APIs** | Drug labels (contraceptives, HRT, fertility meds) | Free API |
| **ClinicalTrials.gov API** | IVF/condition trial finder feature | Free API |

## Tier 2 — Professional societies (guideline reference + patient handouts; cite/link, don't copy)
- **ACOG** (US OB/GYN college) — clinical practice guidelines + patient FAQs (acog.org/womens-health). Reference/link; content licensing via ACOG store.
- **RCOG** (UK) — patient information leaflets, green-top guidelines.
- **NICE** (UK) — evidence-based condition pathways (menorrhagia, endo, fertility, menopause NG23).
- **The Menopause Society (formerly NAMS)** — menopause position statements, MenoNotes handouts.
- **ASRM / ESHRE** — fertility & IVF guidelines and patient resources (SART for IVF success-rate data; sart.org).
- **FIGO** — international gyn standards (AUB classification PALM-COEIN).
- **FSRH** (UK) — contraception guidance (UKMEC).
- **Endometriosis societies** (World Endometriosis Society, Endometriosis UK), **PCOS**: International Evidence-based PCOS Guideline (Monash), **IAPMD** for PMDD (DRSP screening tool).

## Tier 3 — Licensed patient-education vendors (optional, paid, fastest content scale-up)
- **Healthwise** — gold standard licensed patient content, multi-language, API delivery.
- **EBSCO Health Library / StayWell (WebMD Ignite) / Elsevier Patient Engagement** — alternatives.
- **Mayo Clinic / Cleveland Clinic syndication** — brand-name licensing (expensive).
Decision: start Tier 1+2 (free) with our own medically-reviewed rewriting; evaluate Healthwise license at revenue stage.

## Clinical logic & validated instruments to embed as tools
- Cycle/fertility: WHO/FIGO normal-cycle parameters; Fehring fertile-window research; BBT & LH-surge rules.
- Screeners (all free/validated, check per-instrument permissions): **EPDS** (postpartum depression), **PHQ-9/GAD-7** (mood/anxiety), **DRSP** (PMDD), **MRS / Greene Climacteric Scale** (menopause), **PBAC** (heavy bleeding), **Ferriman-Gallwey** (hirsutism self-report), **AUB PALM-COEIN** education.
- Calculators: due date (Naegele + ultrasound rules), gestational age, ovulation/fertile window, BMI, iron intake, HRT decision-support education, IVF medication calendar, contraception effectiveness comparison (WHO/CDC data).
- Growth/pregnancy data: WHO fetal growth charts, weight-gain-in-pregnancy (IOM guidelines).

## Multilingual source strategy
- EN: full pipeline from Tier 1/2.
- ES: MedlinePlus + OWH + CDC Spanish versions (free, high quality).
- AR/FR: WHO (AR/FR), UNFPA Arabic materials, translated-and-medically-reviewed Femio originals (translation portal workflow with reviewer sign-off).

## Rules of use (compliance)
1. Public-domain (US Gov) → reuse freely, still cite.
2. CC-licensed (WHO, NHS OGL) → attribute exactly per license; respect NC clauses (WHO NC → our usage in a freemium app needs review or rewrite-from-facts approach).
3. Society guidelines → facts are not copyrightable; express in our own words + cite. Never reproduce PDFs.
4. Every page: author, medical reviewer, sources list, last-reviewed date, next-review due (12 mo), disclaimer ("educational, not medical advice").
5. Editorial policy page published on site (E-E-A-T requirement for Google health rankings — YMYL category).
